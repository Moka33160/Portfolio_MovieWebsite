# Portfolio de Mathis Gesson

Portfolio en français, anglais, espagnol, allemand et néerlandais : projets, expériences professionnelles à INRAE, CV et rapport téléchargeables, contact et démonstrations.

## Développement

```sh
cd website2
npm ci
npm run dev
```

## Publication

Le workflow GitHub Actions `.github/workflows/pages.yml` vérifie, compile et déploie le site sur GitHub Pages à chaque mise à jour de `main`. La source Pages du dépôt doit être **GitHub Actions**.

Voir [la documentation du site](website2/README.md) pour les fonctionnalités, les traductions et les conditions de fonctionnement des démonstrations. L’interface Anicard est incluse ; son API n’est pas hébergée par GitHub Pages.
